## 일하는 방식

> **사람과 사물과 인공지능을 연결한다. 엄청 많이!**

- **자유와 책임.** 출퇴근은 각자 정하고, 크리티컬하지 않은 일은 먼저 처리한 뒤 공유합니다.
- **프로게이머처럼.** 자기 역할을 압도적으로 해내고, 동료에게 어시스트하고, 다음 수를 먼저 제안합니다.
- **판을 바꾸는 수준.** 이 사람이 지나간 자리는 다음 사람에게 더 쉬워져 있어야 합니다.

자세한 내용은 **[오픈아이오티 컬쳐덱](https://drive.google.com/file/d/1cYIjkMDLOoMDjJZvqb9dzOfI0y7EmCCe/view)** 에 있습니다.
